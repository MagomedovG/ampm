# Сайт фотостудии

Лёгкий адаптивный одностраничный сайт без внешних зависимостей и этапа сборки.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска откройте `http://localhost:4173`.

## Настройка перед публикацией

Все изменяемые данные находятся в `config.js`:

- `studioName` — название студии;
- `bookingUrl` — общая ссылка YCLIENTS;
- `rooms.*.zones` — количество зон в каждом пространстве;
- `rooms.*.bookingUrl` — отдельная ссылка YCLIENTS для зала, если она есть;
- `firstHour` и `nextHour` — цены.

Пока ссылка YCLIENTS не задана, кнопки бронирования ведут к честному информационному сообщению на странице и не открывают вымышленный сервис записи.
